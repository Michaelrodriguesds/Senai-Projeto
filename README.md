# Calculadora

Calculadora simples feita com HTML, CSS e JavaScript, como projeto do curso de Desenvolvedor de Sistemas do SENAI.

## Funcionalidades

- Digitar números
- Ponto decimal
- Soma
- Botão `C` para limpar

## Arquivos

- `index.html`: estrutura da calculadora
- `estilo.css`: aparência e organização dos botões
- `javascript.js`: lógica da calculadora

## Como usar

Abra o arquivo `index.html` no navegador.
